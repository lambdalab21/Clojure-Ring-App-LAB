# Intro
To set up **[Reitit](https://github.com/metosin/reitit)**, a data-driven routing library for Clojure and ClojureScript, follow these steps to install the library, define routes, and create a functional handler.

## 1. Installation

Add the Reitit dependency to your project. For a standard Ring-based web server, use `reitit-ring`. 

**project.clj**
```clojure
  :dependencies [[org.clojure/clojure "1.11.1"]
                 [ring "1.15.3"]
                 [ring/ring-devel "1.15.3"]
                 [metosin/reitit "0.9.2"]] ;<-- ADDED THIS!!
```


## 2. Define Your Routes

In Reitit, routes are defined as a **recursive vector of vectors**. This data-driven approach allows for clear nesting and shared route data (like middleware). 

``` clojure
(require '[reitit.ring :as ring])

(def routes
  ["/api"
   ["/ping" {:get (fn [_] {:status 200 :body "pong"})}]
   ["/user/:id" {:get (fn [{:keys [path-params]}]
                        {:status 200 :body (str "User ID: " (:id path-params))})}]])
```

## 3. Setup the Router and Handler

The `ring-handler` converts your route data into a function that can be served by web servers like Jetty or Http-kit. 

``` clojure
(def app
  (ring/ring-handler
    (ring/router routes)
    (ring/create-default-handler))) ;; Returns 404 for unknown routes
```




```clojure
(ns workflow.core
  (:require
   [reitit.ring :as ring] ;; Added Reitit
   [ring.adapter.jetty :as jetty]
   [ring.middleware.reload :refer [wrap-reload]]
   [ring.middleware.refresh :refer [wrap-refresh]]
   [hiccup2.core :as h])
  (:gen-class))

;; 1. Define your page handler (same as before)
(defn home-page [request]
  {:status 200
   :headers {"Content-Type" "text/html"}
   :body (str (h/html [:html
                       [:head [:title "Reitit + Hiccup2"]]
                       [:body
                        [:h1 "Welcome to Reitit"]
                        [:p "Request URI: " (:uri request)]]]))})

;; 2. Setup the Reitit Router
;; Routes are defined as a vector of vectors.
(def app
  (ring/ring-handler
    (ring/router
      ["/" {:get home-page}]
      ["/ping" {:get (fn [_] {:status 200 :body "pong"})}])))

(defonce server (atom nil))

;; 3. Update start to use the router
(defn start []
  (reset! server
          (jetty/run-jetty 
            ;; wrap-reload needs a Var quote (#'app) to pick up route changes
            (wrap-refresh (wrap-reload #'app)) 
            {:port 8082 :join? false})))

(defn start []
  (reset! server
          (jetty/run-jetty 
           (-> #'my-handler
               wrap-reload   ; Reloads code on server
               wrap-refresh) ; Triggers refresh in browser
           {:port 8081 :join? false})))
```
