# Starter Code
```clojure

(ns workflow.core
  (:require
   [ring.adapter.jetty :as jetty]
   [ring.middleware.reload :refer [wrap-reload]]
   [ring.middleware.refresh :refer [wrap-refresh]]) ; <-- Add this
  (:gen-class))

(defn my-handler [request]
  {:status 200
   :headers {"Content-Type" "text/plain"}  ;; <-- `plaintext` to `html`
   :body "Plain Text"});; <-- need `<head>`  

(defonce server (atom nil))

(defn start []
  (reset! server
          (jetty/run-jetty 
           (-> #'my-handler
               wrap-reload   ; Reloads code on server
               wrap-refresh) ; Triggers refresh in browser
           {:port 8080 :join? false})))

(defn stop []
  (.stop @server))

(defn restart []  
  (stop)
  (start))
```

## Common Categories and Types

- **Application Data:**
    - `application/json`: Used for REST APIs and structured data.
    - `application/pdf`: Standard for PDF documents.
    - `application/xml`: Used for XML structured data.
    - `application/octet-stream`: The **default** for unknown binary files.
    - `application/x-www-form-urlencoded`: Used for basic HTML form submissions.
- **Text Data:**
    - `text/html`: The standard for web pages.
    - `text/css`: Used for cascading stylesheets.
    - `text/javascript`: Used for scripts (note: `application/javascript` is considered obsolete).
    - `text/plain`: The **default** for textual files.
- **Media (Image, Audio, Video):**
    - `image/jpeg`, `image/png`, `image/svg+xml`, `image/webp`: Common web image formats.
    - `audio/mpeg` (MP3), `audio/ogg`, `audio/wav`: Common audio formats.
    - `video/mp4`, `video/webm`: Common video formats.
- **Multipart Types:**
    - `multipart/form-data`: Required for HTML forms that include file uploads.
    - `multipart/byteranges`: Used with 206 Partial Content responses to send multiple parts of a document in one message. 

## Implementation Details

- **Default Behavior:** If no type is specified, browsers often default to `application/octet-stream` for binary or `text/plain` for text, though they may attempt "MIME sniffing" to guess the type unless the `X-Content-Type-Options: nosniff` header is present.
- **Syntax:** Headers can include directives such as `charset` (e.g., `Content-Type: text/html; charset=UTF-8`) or `boundary` for multipart data.
- **Full Registry:** The official, comprehensive list of all registered media types is maintained by the IANA Media Types Registry.


## application/json
```clojure
(ns workflow.core
  (:require
   [ring.adapter.jetty :as jetty]
   [ring.middleware.json :refer [wrap-json-response]] ;; 1. Import JSON middleware
   [ring.middleware.file :refer [wrap-file]]
   [ring.middleware.reload :refer [wrap-reload]]
   [ring.middleware.refresh :refer [wrap-refresh]])
  (:gen-class))

(defn my-handler [request]
  {:status 200
   ;; 2. You no longer need to manually set the header if using wrap-json-response
   :body {:message "Hello World" :status "success"}}) ;; 3. Return a Clojure map

(defonce server (atom nil))

(defn start []
  (reset! server
          (jetty/run-jetty 
           (-> #'my-handler
               (wrap-json-response) ; 4. Converts map to JSON string + sets header
               (wrap-file "public")
               (wrap-reload)   
               (wrap-refresh)) 
           {:port 8080 :join? false})))

```

## appliation/pdf

```clojure
(ns workflow.core
  (:require
   [clojure.java.io :as io]
   [ring.adapter.jetty :as jetty]
   [ring.middleware.file :refer [wrap-file]]
   [ring.middleware.content-type :refer [wrap-content-type]] ; Essential for PDFs
   [ring.middleware.reload :refer [wrap-reload]]
   [ring.middleware.refresh :refer [wrap-refresh]])
  (:gen-class))

(defn my-handler [request]
  ;; This handler only runs if wrap-file DOES NOT find a matching file first.
  {:status 200
   :headers {"Content-Type" "application/pdf"}
   :body (io/file "public/my-document.pdf")}) ; You must return a File object or Stream

(defn start []
  (reset! server
          (jetty/run-jetty 
           (-> #'my-handler
               (wrap-file "public")       ; 1. Look for file in /public folder
               (wrap-content-type)        ; 2. If found, set Type based on extension
               (wrap-reload)              ; 3. Development helpers
               (wrap-refresh)) 
           {:port 8080 :join? false})))

```
